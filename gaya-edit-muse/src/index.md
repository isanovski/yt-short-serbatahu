# index.md — titik masuk

Mulai dari sini setiap kali mau edit video.

1. Baca `konten.md` di folder ini. Isinya peta keputusan, prinsip inti, dan semua angka gaya.
2. Buka file sistem sesuai lini: `SerbaTahu.md`, `Sport.md`, `Eksperimen.md`, atau `LiniLain.md`.
3. Ikuti gerbang kirim di file sistem itu sebelum video dikirim ke Bos.

Daftar semua sistem yang terdaftar resmi ada di `Root.md`. Sistem yang tidak terdaftar di sana bukan standar dan harus dilabeli eksperimen ke Bos.
