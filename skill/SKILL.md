# Serba Tahu — Indeks Style

Channel Serba Tahu (@serbatahumedia) punya **dua style produksi**. Satu video memakai satu style,
tidak dicampur. File ini indeksnya; standar lengkap tiap style ada di foldernya masing-masing.

## 1. Style 2D — Point Nemo

- Standar: `skill/2d/SKILL.md` (Sistem Produksi 2D TERKUNCI, berlaku 17 November 2026)
- Kit: `kit/2d/` (builder panggung peta, referensi peta asli penuh, audio dua stem, timing VO)
- Kit caption opsional: `kit/2d/kit-v6/` (dipakai hanya atas pilihan Bos per episode)
- Isi: animasi 2D flat penuh digambar kode (PIL) di atas peta asli/diagram, kamera zoom/pan kontinu,
  angka sebagai alat peraga, caption kinetik per kata.
- Status: **style utama yang sedang berjalan** untuk produksi baru sejak 17 November 2026.
- Episode: Pesawat 10 Km, Point Nemo, Diomede, Prancis 12 Zona Waktu, Rute Pesawat Lengkung,
  Indonesia Lebih Lebar dari Amerika.

## 2. Style Video — Foto dan Footage Asli

- Standar: `skill/video/SKILL.md` (Standar Produksi v3, dibekukan 12 November 2026, lineage v5)
- Kit: `kit/video/` (template builder v5, referensi Wabah Menari v5, template audio, contoh ambil aset)
- Dokumen desain pendukung: `docs/Standar-Desain-Referensi.md`
- Isi: foto dan footage asli full-frame sebagai tulang punggung, lapisan ilustrasi/kartu penjelas,
  kartu angka raksasa, caption per frasa.
- Status: style kedua Serba Tahu, tersedia penuh di repo ini. Produksi baru saat ini memakai
  style 2D; style Video dipakai bila Bos memintanya.
- Episode: era Petir sampai El Niño 2026 (daftar lengkap di `episodes/DAFTAR.md`).

## Bersama

- `data/` — paket caption dan log produksi semua episode, kedua style.
- `episodes/` — folder produksi per episode; pengelompokan per style ada di `episodes/DAFTAR.md`.
- `gaya-edit-muse/` — panduan gaya edit lintas lini (berisi juga lini lain di luar Serba Tahu).
